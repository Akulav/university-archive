# Polygon Triangulation

A WinForms app that triangulates any polygon you draw.

## Usage

Click on the canvas to add vertices. The polygon is triangulated as you draw.

## Running

- **Prebuilt:** run `Triangulation.exe` (Windows).
- **From source:** open `Furnica.sln` in Visual Studio and press **Start**.

The `Backup/` folder holds an older version of the project.
