# Gnome Visual Novel

A short visual novel made in Unity, telling the story of a gnome who sets out to save his brother.

## Controls

- **Space**: advance the story

## Running

1. Install **Unity 2019.3.10f1** (or a compatible 2019.3.x version).
2. Open this folder as a project in Unity Hub. Unity rebuilds the `Library/` cache on first open.
3. Open the main scene and press **Play**.

## Notes

The code quality is poor and it is not a good learning resource. The project is kept for archival purposes only.
