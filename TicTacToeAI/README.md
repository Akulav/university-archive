# Tic-Tac-Toe AI

A WinForms Tic-Tac-Toe game against a computer opponent driven by the Minimax algorithm.

## Features

- Play as X or O against the AI
- The AI uses Minimax (`Minimax.cs`) to find the best move, so it never loses
- When it can't win, the AI aims for a draw
- **Train AI** button simulates games automatically

## Running

Open `WindowsFormsApp3.sln` in Visual Studio and press **Start**.
