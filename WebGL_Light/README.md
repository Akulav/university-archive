# WebGL Light

An interactive WebGL scene with basic shapes and a configurable light.

## Features

- Create spheres, cubes and pyramids
- Move objects with **W A S D**, rotate them, and scale with the mouse wheel
- Move the light and change its colour
- Remove an object by selecting it in the drop-down and pressing **Del**

## Running

Open `catalin.html` in a browser that supports WebGL. If the browser blocks local files, serve the folder instead:

```bash
python -m http.server
```
