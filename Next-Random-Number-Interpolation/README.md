# Next Random Number Interpolation

My first program. Given the first 100 numbers generated from the same seed, it predicts the 101st.

## Files

- `main.c`: the program
- `codfinal.txt`: an earlier copy of the source

## Running

```bash
gcc main.c -o interpolate
./interpolate
```

## Notes

Kept for nostalgic reasons only. It is not a serious or reliable predictor and should not be used.
