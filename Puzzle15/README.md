# Puzzle 15 Solver

Creates a random 15-puzzle from a seed and solves it in as few moves as possible.

## Algorithms

- Best-First Search (`BestFirstSolver.cs`), using a priority queue
- Breadth-First Search (`BreadthFirstSolver.cs`)
- Depth-First Search (`DepthFirstSolver.cs`)

The solution is shown step by step in a WinForms window.

## Running

Open `Puzzle15.csproj` in Visual Studio and press **Start**.
